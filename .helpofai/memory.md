# Project Memory

This file is project-specific (workspace-scoped).
It stores active tasks, project-specific guidelines, todo lists, and context relevant only to this directory.

## How to Use
- **Task Management**: Use `/projectmemory task add <desc>` or `/projectmemory task complete <n>` to manage tasks.
- **Model Memory**: The model can write to this file using the `remember` tool with `scope='project'` to persist project-specific choices.
- **Manual Editing**: You can edit this file directly to document layout details, build rules, or project context.
